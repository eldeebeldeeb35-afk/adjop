## ١. OmniRoute
المصدر: https://github.com/cheaper-inference/OmniRoute
```bash
npm install -g omniroute
```
بعدين شغّله وافتح لوحة التحكم، وصّل مزوّد واحد على الأقل (حسابك أو مفتاح API)، وشغّل Claude Code من خلاله:
```bash
omniroute run claude
```
**خد بالك**:
- الكود والكلام بتاعك هيروح لأي شركة الموجّه يختارها (DeepSeek، Qwen، Kimi…)، مش Anthropic بس. متستخدموش في حاجة سرية.
- الموديلات التانية أضعف من Claude في الشغل الصعب، فالجودة هتقل لما يحوّل.
- بعض المزودين شروطهم بتمنع الاستخدام ده؛ OmniRoute بيستبعدهم لوحده (`tos: avoid`)، متغيّرش الإعداد ده.

## ٢. claude-mem
المصدر: https://github.com/thedotmack/claude-mem
من جوه Claude Code:
```
/plugin marketplace add thedotmack/claude-mem
/plugin install claude-mem
```
أو من التيرمينال:
```bash
npx claude-mem install
```
**خد بالك**:
- أثناء التسطيب بيعرض «claude-mem observer» بتجربة 30 يوم **بتطلب كارت فيزا**. مش لازم: اختار إن الذاكرة تشتغل على اشتراك Anthropic بتاعك.
- بيبعت إحصائيات استخدام مجهولة؛ اقفلها:
```bash
npx claude-mem telemetry disable
```
- الذاكرة بتتحفظ على جهازك في `~/.claude-mem`.

## ٣. Headroom
المصدر: https://github.com/headroomlabs-ai/headroom
محتاج Python و `uv`:
```bash
uv tool install --python 3.13 "headroom-ai[all]"
```
```bash
headroom wrap claude
```
للتأكد إنه شغال وتشوف التوفير:
```bash
headroom doctor
```
```bash
headroom dashboard
```
للرجوع زي ما كنت:
```bash
headroom unwrap claude
```

## ملاحظات
- **OmniRoute وHeadroom الاتنين «بروكسي»** بيقفوا بين Claude Code والموديل. شغّل واحد بس في الأول وجربه، وبعدين ضيف التاني، عشان لو حاجة باظت تعرف السبب.
- Headroom بيعمل نفس فكرة سكل `token-saver` بس أوتوماتيك. claude-mem بيعمل فكرة `conversation-map` أوتوماتيك. الاتنين ينفعوا مع بعض.
- كل الإضافات دي مش من Anthropic غير رقم ٤.
