# D.I.P — تصميم وفصل ألوان وسلك سكرين

- البراند: D.I.P. صفحة فيسبوك: https://www.facebook.com/profile.php?id=100088481756405
- الخدمات (زي ما هي في `content/site.ts` → `work`):
  1. تصميم للملابس: تيشيرتات وهوديز وشعارات، متجهزة للطباعة من الأول.
  2. فصل ألوان للمطابع: لون لكل شاشة، وتجهيز الدرجات عشان التفاصيل ما تضيعش. لمطبعته أو لأي مطبعة.
  3. طباعة سلك سكرين في مطبعة D.I.P بنفس الألوان المفصولة.
- خط الشغل: التصميم ← فصل الألوان ← تجهيز الشاشات ← الطباعة ← التسليم.

## لما يطلب تجهيز ملف للطباعة
حمّل سكل `print-prepress` (فصل الألوان، spot colors، underbase للقماش الغامق، halftone، الشبكة/mesh، trapping، فحص الملف قبل المطبعة) واتبعه، وخلي الشرح بالمصري ومختصر:
1. اعرف لون القماش، عدد الألوان، مقاس الطباعة، ونوع الحبر (plastisol / water-based).
2. لون لكل شاشة (spot)، ولو القماش غامق ضيف underbase أبيض.
3. الدرجات تتحول halftone بزاوية وتردد مناسب للشبكة.
4. ضيف trapping بسيط بين الألوان المتلامسة وعلامات تسجيل (registration marks).
5. سلّم كل شاشة كفيلم أسود منفصل، مع ملف بروفة ملوّن.
