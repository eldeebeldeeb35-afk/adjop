# هوية حمدي الديب

- **اللوجو**: لوجو القناة بالخط الكوفي المربع `public/brand/logo.png`.
- **الألوان** (من `app/globals.css`):
  | الاسم | اللون | الاستخدام |
  |---|---|---|
  | ink | `#0d0b09` | الخلفية الأساسية |
  | night | `#14110d` | خلفية سكشن |
  | coal | `#1c1813` | سطح |
  | card | `#221d17` | كروت |
  | line | `#3a3128` | خطوط وحدود |
  | cream | `#f1e9dc` | النص |
  | sand | `#b3a690` | نص ثانوي |
  | gold | `#d9ae5f` | الذهبي الأساسي |
  | gold-deep | `#a8813d` | ذهبي غامق |
  ذهبي النجوم في البورتريه `#e0a54a` والإضاءة `#fff1d0`.
- **الخطوط**: Reem Kufi للعناوين واللاتيني، Noto Kufi Arabic للنص، Amiri للآيات القرآنية بس.
- **الإحساس**: خلفية داكنة دافية وذهبي، هادي ومش صريخ. **ممنوع باليتات جديدة.**
- **الصور**: صور حمدي اللي بعتها بس.
- للتصميم من الصفر استخدم `frontend-design` بس جوه الحدود دي.
